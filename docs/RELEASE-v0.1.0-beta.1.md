# HARPHiAN Control v0.1.0 Beta 1

**Feito no Brasil. Feito pra você.**

Primeira versão pública beta para Windows 10 e Windows 11 (64 bits).

## Instalação

1. Baixe `HARPHiAN-Control-Setup-Windows-x64.exe` na seção **Assets** desta release.
2. Execute o instalador e leia os termos de licença.
3. Conclua a instalação e abra o aplicativo pelo atalho.
